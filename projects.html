Surnamerator

A last name generator powered by a small language model (SLM), inspired by my partner's desire for a new surname.

See it in action GitHub →

Challenges

My partner wanted control over the first and final characters of generated names. First characters were easy — initialize the prompt with them. Final characters were harder. I modified the dataset to embed "hints" of the final characters before the regular model input, giving the transformer enough context to predict the ending correctly. It worked remarkably well.

What I Learned

I got my hands dirty coding a transformer from scratch, something I had only used via libraries or read about in papers before this project.

Resources

Special thanks to Andrej Karpathy for inspiring this project with his Zero-to-Hero series.

Azriel Dreambooth

I used DreamBooth to fine-tune a Stable Diffusion model on my cat Azriel and generate a huge variety of AI portraits. Can you tell which is the real photo?

See it in action Colab notebook →

Challenges

Determining training hyperparameters was a huge undertaking. I wrote a Medium article outlining the configurations that worked well.

What I Learned

Getting hands-on experience with diffusion models was great. I got a reminder of the importance of experiment tracking — notating training images, steps, and learning rate helped me produce more consistent results.

Resources

The HuggingFace diffusers class provided a great foundation. The Azriel model won 2nd place in their DreamBooth competition.

Rocketship RRT

A Javascript implementation of a Rapidly-Exploring Random Tree (RRT). The rocket ship uses a search tree to decide how to move around in space and get as close as possible to an orbiting planet.

See it in action GitHub →

Challenges

Determining a simple and decent search methodology was tricky. I created a node queue prioritized by Euclidean distance to the planet. The Euclidean metric causes problems where the closest node can point away from the planet, making that path more costly than others.

What I Learned

I had never written code for a website before, so this was a fun opportunity to write JavaScript and understand how it integrates with HTML and no-code platforms like Webflow.

Scribe

For AssemblyAI's Winter Hackathon, I built Scribe — an automated meeting note-taking app that lets users focus on calls and quickly catch up on anything they missed.

See it in action GitHub →

Challenges

The hackathon was only two days. One core challenge was getting real-time data from web conferencing software — Zoom, Meet, and others don't expose good APIs for this. I ended up using a plugin that read subtitles off a live Google Meet page. Getting raw audio would have made a much better product.

What I Learned

Surprisingly, all the AI-related parts felt trivial. The hardest aspects were building the website and piping data around. Never underestimate boilerplate code.
